# 친구 탭 및 회원 프로필 상세 / 관리 기능 명세서

## 1. 개요
커뮤니티 회원들의 전체 명부 조회, 등급별 필터링, 개별 프로필 카드, 좌우 스와이프 제스처 탐색, 그리고 운영진 전용 실시간 프로필 수정 및 데이터 정리(중복 삭제 / UID 인계) 도구를 제공합니다.

## 2. 등급(Role) 체계 확장: Rookie (신입) 및 OnLeave (외출자)
- **신입(`Rookie`) vs 일반 멤버(`Member`) 구분 및 닉네임 표기 규칙**:
  - **신입 기준 (`Rookie`)**: 벙 참석 횟수가 0회(`attendanceCount === 0`)인 회원은 신입으로 자동 분류됩니다.
    - 닉네임 끝에 **가입일 날짜 뱃지(`entryBadge`, MMDD 예: `1106`)**를 붙여 표시합니다. (예: `가을 수원 기 여 1106`)
  - **일반 멤버 승급 기준 (`Member`)**: 오프라인 벙에 1회 이상 참석(`attendanceCount >= 1`)하여 모임 정산이 완료되면 자동으로 일반 멤버(`Member`)로 승급됩니다.
    - 벙에 1회 이상 참석한 정식 멤버는 닉네임에서 **가입일 날짜를 떼고 깔끔하게 표시**합니다. (예: `가을 수원 기 여`)
    - (단, 점수 마일스톤 티어 뱃지나 운영진이 수여한 특별 뱃지 `customBadge`가 있을 때만 해당 뱃지 표기)
- **외출자 등급 (`OnLeave`)**:
  - 잠시 단톡방을 비우거나 휴면/외출 중인 회원을 위한 등급
  - 뱃지 색상: `--role-onleave: #ea580c` (호박색)
  - 친구 탭의 `외출자` 서브탭에서 모든 회원이 확인 가능
  - 기존 활동 점수는 그대로 보존되어 랭킹 순위표에도 정상 반영
  - 복귀 시 운영진 프로필 편집기에서 원클릭으로 `일반회원`/`VIP` 등으로 즉시 원복 가능

## 3. 하단 네비게이션 5개 탭
1. **[홈]** (`home`): 메인 대시보드 및 공지/일정
2. **[모임]** (`meetings`): 벙 목록/상세/신청/정산
3. **[친구]** (`friends`): 전체 회원 명부 및 등급별 필터
4. **[랭킹]** (`ranking`): 점수 순위표
5. **[내정보]** (`profile`): 개인 프로필 및 설정 (마스터 탭 토글 포함)
*(닉네임 생성기는 친구 탭 및 프로필 내 콤팩트 배너로 바로가기 연동)*

## 4. 친구 탭 (`FriendsPage`)
- **등급 서브탭**:
  - `전체`, `신입`, `일반`, `VIP`, `운영진`, `외출자` (일반 회원 열람 가능)
  - `탈퇴자 🔒`, `방랑자 🔒`, `강퇴자 🔒` (운영진만 열람 가능)
- **전체 리스트 노출 범위 (`activeFilter === 'ALL'`)**:
  - 정상 활동 회원인 **신입(`Rookie`), 일반(`Member`), VIP(`VIP`), 운영진(`Leader`, `Deputy`)**만 표시됩니다.
  - 외출자(`OnLeave`), 탈퇴자(`Withdrawn`), 방랑자(`Wanderer`), 강퇴자(`Expelled`)는 '전체' 탭에서 제외되며 각각의 전용 서브탭에서만 조회됩니다.
- **개인정보 및 보안 필터 (`!isAdmin`)**:
  - 일반 회원은 검색창 검색 시에도 방랑자(`Wanderer`), 강퇴자(`Expelled`), 탈퇴자(`Withdrawn`) 데이터가 노출되지 않도록 서버/클라이언트 양방향 보호 필터가 적용됩니다.
- **본인 최상단 고정 정렬 (0순위 Pinning)**:
  - 어떤 서브탭이나 검색 결과에서든 현재 로그인한 사용자 본인(`currentUser`)이 해당 목록에 포함되어 있다면 **항상 목록의 최상단(제일 첫 번째 카드)**에 고정 표출됩니다.
- **다양한 정렬 옵션 (`Sort By`)**:
  - 검색창 우측 드롭다운을 통해 회원을 즉시 원하는 기준으로 정렬할 수 있습니다:
    1. **점수순 (기본값)**: 본인 최상단 → 운영진 가중치 우선 → 누적 벙점수 높은 순
    2. **이름순 (가나다)**: 본인 최상단 → 닉네임/이름 한글 오름차순
    3. **참석순**: 본인 최상단 → 오프라인 벙 참석 횟수 내림차순
    4. **가입순**: 본인 최상단 → 가입일자/생성일자 최신순
- **서브탭 필터 상태 보존 및 URL 라우팅 (`State Lifting`)**:
  - 활성 필터 탭(`activeFilter`: 전체, 방랑자, 강퇴자, 신입 등)과 검색어(`searchQuery`)를 상위 컴포넌트(`App.jsx`) 상태로 보존합니다.
  - 특정 서브탭(예: `방랑자 🔒`)에서 회원을 선택해 상세 프로필로 진입한 뒤 역할을 수정(예: 방랑자 → 강퇴자)하고 뒤로가기(`onBack` 또는 브라우저 `popstate`)를 눌러도, **'전체'로 튕기지 않고 직전에 보고 있던 해당 서브탭(`방랑자 🔒`)으로 즉시 복귀**합니다.
  - 브라우저 히스토리 URL에 서브탭 쿼리 파라미터(`/friends?filter=Wanderer`)가 연동되어 브라우저 물리 뒤로가기 시에도 동일하게 복원됩니다.
- **실시간 검색**: 닉네임, 본명, 지역 검색 지원
- **회원 카드**: 뱃지, 프로필 사진/아바타, 등급, 지역, 벙 점수 요약 표시
- **프로필 이동**: 회원 카드 클릭 시 `memberUidList`와 현재 활성 필터(`activeFilter`)를 함께 전달하여 프로필 화면으로 이동

## 5. 회원 이름 규칙 및 검증 규격 (`Name Validation Rules`)
- **한글 1자 이상 3자 이하 규격**:
  - 회원의 이름(활동명/실명)은 반드시 **한글 1자~3자**이어야 합니다 (정규식: `/^[가-힣]{1,3}$/`).
  - 영문, 숫자, 공백, 특수문자, 4자 이상은 등록 및 수정이 불가합니다.
- **모임 내 고유성(Unique) 원칙**:
  - 힐링78 커뮤니티 내에서 모든 회원의 이름은 완전히 유일해야 합니다 (동명이인 불가).
  - 다른 회원이 이미 사용 중인 이름으로는 신입 가입, 닉네임 생성, 내 정보 수정을 진행할 수 없습니다.
  - (단, 과거 활동 이력 승계 신청을 통해 본인의 옛 계정을 연동하는 경우는 본인 계정이므로 허용됩니다.)

## 6. 회원 프로필 상세 (`MemberProfilePage` / `/members/:uid`)
- **URL 딥링크 지원**: `/members/:uid` 경로 지원 및 카카오톡 공유 시 회원 닉네임 기반 타이틀 메타 태그 적용
- **좌우 스와이프 탐색 (모바일)**:
  - 터치 스와이프(Touch Start/End) 제스처 지원 (임계값 50px)
  - 현재 필터링된 회원 목록 내에서 이전/다음 회원으로 매끄럽게 전환
  - 상단 이전(`‹`)/다음(`›`) 버튼 및 카운터(`3 / 25`) 제공
- **참여 이력**: 해당 회원이 참여한 벙 목록 및 일시 표시
- **운영진 인라인 편집기**:
  - 본명(`realName`), 거주지역(`city`), 성별(`gender`), 결혼여부(`maritalStatus`), 등급(`role`), 가입일(`joinedAt`), 가입뱃지(`entryBadge`), 특별뱃지(`customBadge`)를 모달 없이 즉시 수정/저장 (기존 연고지/고향 필드는 거주지역 하나로 완전 통합됨)
- **카카오 UID 계정 인계(연계) 및 무결성 보장**:
  - 기기 변경 또는 카카오 계정 재가입으로 새 UID가 발급된 경우 기존 회원의 모임 참여, 점수 로그, 온보딩 기록을 안전하게 새 UID로 병합 및 인계(`reassignMemberUid`)
  - **가상 UID 히스토리 영구 보존**: 구 계정 문서 삭제 시 새 계정의 `subUids` 배열에 과거 가상 UID를 자동 추가하여 과거 코드로 검색/조회 시에도 새 계정이 안전하게 매칭되도록 보장
  - **스냅샷 키 동기화**: 모임의 `memberScoreSnapshots` 키도 과거 UID에서 새 카카오 UID로 자동 치환하여 점수 이력 무결성 보존
  - **방장(쭈) 계정 단일화**: 과거 임시 더미 문서(`kakao:1001`)를 완전 정리하고 실제 로그인 계정(`kakao:5173773611`)의 `subUids`에 등록하여 단일 361점(`🥇` 금 뱃지) 계정으로 확정

## 7. 마스터 관리자 도구 (`SuperAdminPage`)
- **유사 이름 검색 및 중복 회원 삭제**:
  - 탈퇴자/중복 생성된 계정을 이름 기반으로 검색
  - 2단계 안전 확인(`useArmedAction`) 후 영구 삭제 처리
- **UID 인계 콘솔**:
  - 인계 요청자 및 회원 목록에서 원클릭으로 선택하여 안전하게 UID 데이터 마이그레이션 실행

## 8. 활동 지역(`city`)과 벙점수 기준 지역(`homeCity`)의 선택적 분리 규격 (Progressive Disclosure)

### (1) 도입 배경 및 문제 해결
- 힐링78 커뮤니티는 닉네임 규격 `[이름 지역 결혼 성별 뱃지]`에서 **'지역'(`city`)** 하나만 기본 사용합니다.
- 99%의 일반 회원은 활동 지역과 실제 거주지가 일치하므로, 프로필에 '거주지'와 '홈시티'라는 두 개의 유사 필드가 노출되면 사용자 혼선이 크게 발생합니다.
- 반면 직장 파견, 주말부부, 본가 거주 등의 사유로 닉네임 표기 활동지(예: `서울`)와 타도 원정 등 벙점수 판정 기준지(예: `전주`)를 분리 적용해야 하는 특수 회원이 존재합니다.
- 이를 위해 **점진적 공개(Progressive Disclosure) 패턴**을 도입하여 평소에는 입력을 숨겨 혼선을 없애고, 필요한 회원만 선택적으로 분리 지정할 수 있도록 표준화하였습니다.

### (2) UI 및 인터랙션 규격
1. **내 정보 수정 (`ProfilePage.jsx`) & 운영진 회원 편집 (`MemberProfilePage.jsx`)**:
   - 거주 지역 입력란 바로 아래에 체크박스 배치:
     - `[✓] 활동 지역과 벙점수 기준 지역이 다릅니다`
     - 안내 문구: *"체크하지 않으면 닉네임의 거주 지역을 기준으로 벙점수가 자동 계산됩니다. 본가나 실제 거주지가 달라 벙점수 기준 지역을 따로 적용해야 할 때만 체크해 주세요."*
   - **체크 해제 상태 (기본값)**:
     - 추가 입력창 숨김.
     - 저장 시 `homeCity`는 닉네임 거주 지역(`city`)과 항상 100% 자동 동기화 (`homeCity = city`).
   - **체크 상태**:
     - 아래에 `🏠 벙점수 기준 지역 (홈시티)` 입력창(`RegionInput`)이 동적으로 노출.
     - 닉네임 표기(`city`)와 벙점수 계산 기준지(`homeCity`)가 분리 저장됨.
2. **읽기 전용 프로필 표시 규격**:
   - `homeCity`와 `city`가 일치하는 일반 회원은 `거주 지역: 서울`만 심플하게 표시.
   - 분리된 특수 회원은 `거주 지역: 서울 (벙점수 기준: 전주)` 형태로 시각적 피드백을 명확히 제공.

### (3) 벙점수 계산 (`communityRules.js`) 및 과거 이력 무결성
- **벙점수 판정 순서**:
  - `homeCity`가 명시적으로 다르게 지정된 경우 `homeGroup`을 원정 판정의 기준으로 우선 적용하고, 미지정 회원은 `cityGroup`을 사용합니다.
- **과거 벙점수 안전 보장**:
  - 이미 마감된 과거 벙 기록은 당시 정산 스냅샷(`memberScoreSnapshots`) 및 원천 텍스트 기록으로 영구 확정되어 있습니다.
  - 따라서 회원이 오늘 거주지나 벙점수 기준지를 변경하더라도 **과거에 부여된 벙점수 및 뱃지는 절대 소급 변경되지 않으며**, "변경 이후 참석하는 신규 벙"부터 새 거주지 기준으로 벙점수가 계산됩니다.
