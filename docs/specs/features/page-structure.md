# Page Structure and Navigation Specification

## Overview
Healing78 커뮤니티 관리 시스템의 전체 화면 흐름과 하위 주소 라우팅(`/`, `/meetings`, `/ranking`, `/nickname`, `/profile`, `/login`, `/admin`), 모바일 상단 20자 내외 핵심 요약 헤더, 그리고 화이트(`#FFFFFF`) & 로즈 핑크·바이올렛 테마 기반 리스트형 UI 규격을 정의합니다.

모든 페이지는 단일 React 코드베이스에서 PC 웹(좌측 사이드바)과 모바일 웹/앱(원형 로고 + 20자 핵심 요약 상단 헤더 + 아이콘 하단 탭바 + 구분선 리스트 뷰)에 맞게 적응형(Adaptive)으로 렌더링됩니다.

## Business Rules & Logic

### 1. Sub-Route Navigation, Guest Viewing & Onboarding Flow
- **하위 주소별 비로그인 열람 허용 정책:**
  - 카카오톡 채팅방에 공유된 하위 주소(`/meetings`, `/meetings?id=...`, `/ranking`, `/nickname` 등)를 클릭했을 때 로그인 전이라도 즉시 해당 정보를 열람할 수 있습니다.
  - 참석 신청, 새 모임 개설, 내 정보 수정 등 계정 권한이 필요한 액션을 실행할 때만 `/login` 화면으로 안내합니다.
- **모바일 최상단 20자 요약 헤더 및 페이지 타이틀 동기화 (`src/core/routeMeta.js`):**
  - 각 하위 주소 및 선택된 모임(`?id=`)에 따라 브라우저 타이틀(`document.title`)과 모바일 최상단 헤더 문구를 **20자 내외 핵심 정보**(예: `[11/08 서울] 주말 성수동 번개`, `신입 규격 닉네임 생성·변경`, `활동랭킹 1위 김힐링(14점)`)로 동적 갱신합니다.
  - 상단 헤더 및 각 모임 항목의 `[🔗 공유]` 버튼 클릭 시 `20자 핵심 요약 + 하위 주소 링크`가 함께 복사·공유됩니다.
- **신규 회원 온보딩 (`/login`):**
  - 로그인 화면 상단에 `Healing78 (since 2024)` 대표 이미지를 대형 히어로 배너로 노출하고, 앱 내부에서는 상단 헤더의 작은 원형 아이콘으로 심플하게 표시합니다.
  - 카카오 로그인 완료 후 Firestore `members` 컬렉션에 프로필이 없는 신규 회원은 자동으로 온보딩(프로필 초기 설정) 화면으로 이동합니다.
  - 입력 항목: 실명(`realName`), 거주 지역(`city`), 원정 기준 연고지(`homeCity`), 결혼 여부(`single`/`married`/`divorced`), 성별(`남`/`여`).
  - 온보딩 완료 시 가입일(`MMDD`)을 기본 뱃지(`badge`)로 하여 규격 닉네임이 생성되며, 별도 승인 대기 없이 즉시 **`일반회원(Member)`** 자격으로 메인 화면에 진입합니다 (운영진이 사후에 역할 및 상태 관리).

### 2. Main Navigation Structure
- **기본 5개 메뉴 (모바일 하단 아이콘 탭바 & PC 사이드바):**
  1. **홈 (`/`, `home`):** 공지/규칙, 내 프로필·닉네임·3열 요약(점수·순위·참석횟수), 진행 예정 모임(벙) 빠른 참석 및 개별 공유, TOP 5 랭킹 프리뷰.
  2. **모임(벙) (`/meetings`, `meetings`):** 모임 목록 조회 및 개별 모임(`?id=`) 공유, 참석 신청, 모임 개설, 벙주/운영진 모임 마감 및 점수 정산.
  3. **랭킹·친구 (`/ranking`, `ranking`):** 전체 누적 랭킹, 이번 달 랭킹, 지역별 친구 검색, 내 점수 적립 상세 내역.
  4. **신입닉네임 (`/nickname`, `nickname`):** 신입 회원 이름 변경 및 오픈채팅방 규격 닉네임 자동 생성·원클릭 복사 전용 페이지.
  5. **내 정보 (`/profile`, `profile`):** 프로필 수정, 규격 닉네임 자동 갱신 및 원클릭 복사, 내 참석/뱃지 현황 및 테스트용 계정 전환기.
- **조건부 6번째 메뉴 (운영진 전용):**
  6. **운영 관리 (`/admin`, `admin`):** 로그인한 회원의 역할(`role`)이 `Leader`(방장) 또는 `Deputy`(부방장)일 때만 노출됩니다.

### 3. Page-by-Page Specifications

#### A. Home Page (`홈`)
- **공지 및 커뮤니티 규칙 배너:** 운영진이 설정한 주요 공지사항 및 닉네임/벙 규칙 요약 노출.
- **내 상태 요약 카드:** 현재 규격 닉네임(원클릭 복사 버튼 포함), 회원 등급(`role`), 누적 점수(`totalScore`), 전체 순위, 총 벙 참석 횟수(`attendanceCount`) 표시.
- **다가오는 모임(벙) 프리뷰:** 현재 모집 중인 모임 카드 목록 및 즉시 `[참석 신청]` 버튼 제공.
- **TOP 5 랭킹 프리뷰:** 상위 5명의 닉네임과 총점 요약 및 `[랭킹 전체보기]` 이동 링크 제공.

#### B. Meetings Page (`모임(벙)`)
- **서브 탭 구성:** `[진행 예정 | 종료된 모임 | 내 모임]` 3개 탭으로 필터링합니다.
- **모임(벙) 개설 자격 규칙:**
  - **1회 이상 모임에 참석한 회원(`attendanceCount >= 1`)** 또는 **운영진(`Leader`, `Deputy`)**만 새로운 모임(벙)을 개설할 수 있습니다.
  - 참석 횟수가 `0회`인 신규 회원이 `[+ 벙 개설하기]` 버튼을 클릭하면 `"모임(벙)에 1회 이상 참석한 회원만 새 모임을 개설할 수 있습니다."` 안내 메시지를 표시하고 개설을 제한합니다.
  - 일반 회원(`attendanceCount >= 1`)은 **자율/번개 모임(`Casual`)**을 개설할 수 있으며, 운영진(`Leader`, `Deputy`)은 **공식 모임(`Official`)**과 **자율/번개 모임(`Casual`)**을 모두 개설할 수 있습니다.
- **참석 신청 및 2단계 점수 정산 프로세스:**
  1. **사전 참석 신청 (`모집중` 상태):** 회원들이 모임 카드에서 `[참석 신청]`(또는 `[신청 취소]`)을 클릭합니다. 모임 지역(`location`)이 회원의 연고지(`homeCity`)와 다를 경우 `원정 +2점 대상` 안내 뱃지를 자동 표시합니다.
  2. **모임 마감 및 점수 정산 (`정산 완료` 상태):** 모임 종료 후 **해당 모임의 벙주(개설자, `hostUid`) 또는 운영진(`Leader`, `Deputy`)**이 신청자 명단에서 실제 참석자를 체크한 뒤 `[모임 마감 · 점수 정산]` 버튼을 실행합니다.
  3. **점수 및 참석 횟수 자동 반영:** 정산 확정 시 실참석자 전원에게 **기본 참석 점수(`+1점`)**, 타지역 원정 해당 시 **원정 보너스(`+2점`)**, 그리고 **누적 참석 횟수(`attendanceCount + 1`)**가 일괄 반영됩니다.

#### C. Ranking & Score Page (`랭킹·점수`)
- **서브 탭 구성:** `[전체 누적 랭킹 | 이번 달 랭킹 | 내 점수 상세 내역]` 3개 탭으로 구성합니다.
- **검색 및 필터:** 회원 닉네임/이름 검색창 및 거주 지역(`city`) 필터를 제공합니다.
- **점수 구성 표시:** 각 회원의 총점(`totalScore`)뿐만 아니라 **기본 참석 점수**, **원정 보너스 점수**, **이벤트 수동 점수** 세부 내역을 함께 표시합니다.

#### D. My Profile & Nickname Page (`내 정보`)
- **프로필 수정 및 규격 닉네임 자동화:**
  - 실명, 거주 지역, 연고지, 결혼 여부, 성별을 수정하면 즉시 `[이름] [지역] [결혼여부] [성별] [뱃지]` 규격에 맞춘 닉네임이 자동 생성됩니다.
  - **`[닉네임 원클릭 복사]`** 버튼을 제공하여 카카오톡 오픈채팅방 프로필에 바로 붙여넣을 수 있도록 지원합니다.
- **뱃지(`badge`) 자동 반영 규칙:**
  - 신규 가입 시 기본 뱃지는 가입일 4자리(`MMDD`, 예: `0829`)로 설정되며, 참석 횟수나 등급 변화(또는 운영진 부여 특수 뱃지)에 따라 자동 반영됩니다.

#### E. Admin Management Page (`운영 관리` - 방장/부방장 전용)
- **서브 탭 구성:**
  1. **회원·역할 관리:** 전체 회원 목록 조회(PC는 다중 컬럼 테이블, 모바일은 검색+카드 모달), 역할 변경(`Leader`, `Deputy`, `VIP`, `Member`, `Wanderer`, `Withdrawn`, `Expelled`), 뱃지(`badge`) 수정 및 닉네임 규격 준수 점검.
  2. **수동 점수 부여·차감:** 대상 회원 선택 후 이벤트 점수(`+` 또는 `-`)와 지급/차감 사유를 입력하여 즉시 반영하고 점수 로그(`scoreLogs`)를 기록.
  3. **공지 및 역할/규칙 설정:** 홈 화면 상단에 노출되는 공지사항 문구 및 커뮤니티 운영 규칙 안내 수정.

## Data Schema & API

### Updated Member Schema (`members`)
- `uid`: string (Firebase Auth UID)
- `realName`: string (실명)
- `city`: string (거주 지역 - 닉네임 표시용)
- `homeCity`: string (연고지 - 원정 보너스 +2점 판별용)
- `maritalStatus`: `'single' | 'married' | 'divorced'` (미혼 `'미'`, 기혼 `'기'`, 돌싱 `'돌'`)
- `gender`: `'남' | '여'`
- `role`: `'Leader' | 'Deputy' | 'VIP' | 'Member' | 'Wanderer' | 'Withdrawn' | 'Expelled'`
- `badge`: string (가입일 `'MMDD'` 또는 등급/이벤트 뱃지)
- `attendanceCount`: number (정산 완료된 누적 모임 참석 횟수 - `>= 1`일 때 벙 개설 가능)
- `baseScore`: number (누적 기본 참석 점수)
- `expeditionScore`: number (누적 원정 보너스 점수)
- `eventScore`: number (누적 운영진 수동 이벤트 점수)
- `totalScore`: number (`baseScore + expeditionScore + eventScore`)

### Updated Meeting Schema (`meetings`)
- `id`: string
- `title`: string (모임 제목)
- `date`: string (모임 일시 ISO 문자열 또는 Timestamp)
- `location`: string (모임 지역 - 원정 판별 기준)
- `placeDetail`: string (상세 장소 안내)
- `hostUid`: string (벙주 UID)
- `hostNickname`: string (벙주 규격 닉네임)
- `type`: `'Official' | 'Casual'` (공식 모임 / 자율·번개 모임)
- `status`: `'open' | 'settled'` (`open` = 모집/진행중, `settled` = 마감 및 점수 정산 완료)
- `applicants`: array of string (사전 참석 신청자 UID 목록)
- `confirmedParticipants`: array of string (정산 확정된 실참석자 UID 목록)
- `description`: string (모임 상세 설명)

## Edge Cases & Validation
- **0회 참석 회원의 벙 개설 시도:** `member.attendanceCount < 1`이면서 운영진(`Leader`, `Deputy`)이 아닌 경우, UI에서 개설 모달 진입을 차단하고 안내 배너/토스트를 노출합니다.
- **중복 정산 방지:** 이미 `status === 'settled'` 상태인 모임은 재정산 버튼을 비활성화하여 점수와 참석 횟수가 중복 가산되지 않도록 보장합니다.
- **강퇴/탈퇴 회원의 접근 제어:** `role`이 `'Withdrawn'`(탈퇴자) 또는 `'Expelled'`(강퇴자)인 경우 메인 기능(참석 신청, 개설) 버튼을 비활성화하고 안내 문구를 표시합니다.

## Test Scenarios
1. **신규 가입 및 온보딩 흐름 검증:**
   - 미등록 상태로 로그인 시 온보딩 화면이 표시되고, 프로필 저장 즉시 `일반회원(Member, 참석 0회)`으로 홈 화면에 진입하는지 확인.
2. **모임 개설 자격 검증 (1회 참석 조건):**
   - 참석 횟수가 `0회`인 일반 회원이 `[+ 벙 개설]` 클릭 시 안내 문구가 뜨며 제한되고, 모임 1회 참석 정산 완료(`attendanceCount: 1`) 후에는 정상적으로 자율벙 개설 모달이 열리는지 확인.
3. **모임 마감 및 원정 점수 정산 검증:**
   - 연고지(`homeCity`)가 `'서울'`인 회원이 `'부산'` 모임에 참석 후 벙주가 `[모임 마감 · 점수 정산]`을 실행하면 기본 `+1점` + 원정 `+2점` = 총 `+3점`과 참석 횟수 `+1회`가 즉시 반영되는지 확인.
4. **운영진 조건부 메뉴 및 권한 검증:**
   - 일반 회원일 때는 하단 탭이 4개(`홈`, `모임(벙)`, `랭킹·점수`, `내 정보`)이고, `방장(Leader)` 또는 `부방장(Deputy)`일 때 5번째 `[운영 관리]` 탭이 활성화되어 역할 변경 및 수동 점수 부여가 동작하는지 확인.
